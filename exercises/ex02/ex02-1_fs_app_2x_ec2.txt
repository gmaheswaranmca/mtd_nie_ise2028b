Full Stack Application Deployment 
1. Backend Application Server (EC2) and Deployment of Backend App
    FastAPI app + sqlite database 

    Steps: 
        1.1. Create Security Group 
            security group: app_server_sg 
                Inbound 
                    1. SSH 22, AnywhereIPv4
                    2. TCP 8000, AnywhereIPv4
                Outbound 
                    1. All Traffic, AnywhereIPv4
        1.2. Create Key Pair 
            key pair: app_server_key
        1.3 Launch Instance 
            ec2 instance: app_server, amazon linux                    
            security group: app_server_sg
            key pair: app_server_key  
        1.4 update linux, install git, clone repo, 
            install python, install python packages, 
            run the backend app using uvicorn server at 8000.

            1.4.1 Make ssh connection from terminal or from browser 
                ssh -i "app_server_key.pem" ec2-user@ec2-3-26-155-134.ap-southeast-2.compute.amazonaws.com
            1.4.2 Below command run in ssh:
                $ sudo dnf update -y
                $ sudo dnf install git -y
                $ git clone https://github.com/gmaheswaranmca/mtd_nie_ise2028b.git
                $ cd /home/ec2-user/mtd_nie_ise2028b/exercises/ex02/server/scripts
                $ chmod +x ser2.sh
                $ ./ser2.sh
                To Check 
                $ cd /home/ec2-user/mtd_nie_ise2028b/exercises/ex02/server 
                $ tail -f app.log
                $ Ctrl+C  
            1.4.3. Open Backend App in browser using Swagger 
                URL: http://your_public_ip:8000/docs
                Actual URL:  http://16.176.127.140:8000/docs
