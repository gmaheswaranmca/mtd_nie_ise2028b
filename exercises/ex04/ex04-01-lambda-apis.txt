Deployment of API to expose outside 
    Consuming from outside lambda serverless 

API Gateway is the solution.

Steps:
-> Top page of the hello function
-> Add Trigger
-> Add trigger page is opened
-> Trigger configuration
    Select API Gateway 
    Intent: Create a new API
    API Type: HTTP API
    Security: Open 
    -> Add 
-> Check under Configuration tab 
    -> API Gateway: hello-API is added 
    -> Open API End Point in browser 
         https://ljbcmiiuh4.execute-api.ap-southeast-2.amazonaws.com/default/hello

         Response: "Hello from Maheswaran!"
