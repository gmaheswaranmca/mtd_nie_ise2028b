Load Balancer - Experiment
Overview:
    - Two EC2 instances for web site
        -> site_servers :: no of instances=2 
            -> site_servers_sg + site_servers_key  
    - ALB : alb1
        -> alb1_sg 
        -> Target Group : tg1
            tg1 will targest site_servers 

Procedure:
1. Security Group : site_servers_sg
-> Search EC2 -> Security Groups -> Create Security Group 
-> name: site_servers_sg 
    Inbound Rules
        1. SSH AnywhereIPv4
        2. HTTP AnywhereIPv4
2. Key Pair : site_servers_key
3. EC2 instances = 2 = site_servers
    security group = site_servers_sg
    key pair: site_servers_key

#!/bin/bash
yum update -y
yum install -y httpd

systemctl start httpd
systemctl enable httpd

echo "<h1>Server is up and running!</h1>" > /var/www/html/index.html
echo "<p>Hello from EC2 Instance - $(hostname -f)</p>" >> /var/www/html/index.html
echo "<p>Date: $(date)</p>" >> /var/www/html/index.html

Wait for status check 

Then open the web site in browser:
    1. http://first_instance_ip
    2. http://second_instance_ip 
4. Target Group : tg1
-> Left Menu -> Under Load Balancing category 
-> Target Groups -> Create Target Group
-> Target type: instances 
   Target group name : tg1 
   Protocol: HTTP 80  (Default)
   IP address type: IPv4  (Default)
   Protocol version: HTTP1 (Default)
   Health checks: HTTP /
-> Next in right bottom 
-> Available instances (2/2)
    Select our two instances 
    Ports for the selected instances: 80
    Include as Pending Below 

    Review targets contains our EC2 instances 
-> Next 
-> Review the Summary 
-> Create Target Group 

Target Group Created now. 
5. ALB : alb1
-> Left Menu -> Load Balancers 
-> DropDown of Create Load Balancer 
    -> Compare Load Balancers Types
    -> Create under Application Load Balancer 
    -> name: alb1 
       scheme: Internet-facing
       Load balancer IP address type: IPv4 
       Availability Zones and subnets
        Tick all the three AZs and Subnets 
    -> security group: site_servers_sg 
    -> Listeners and routing
        Listner = HTTP:80
        Forward to target groups
        Target group: tg1
    -> Check Summary
    -> Create Load Balancer 
    Created Load Balancer
    -> Check status of LB 
        Status : Provisioning -> Active 
    -> If status = Active 
        Open the url in browser 
        URL: http://LB_dns 
        ie http://alb1-854507959.ap-southeast-2.elb.amazonaws.com

    - Delete Load Balancer
