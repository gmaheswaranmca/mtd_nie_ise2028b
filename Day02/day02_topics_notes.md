# AWS One-Line Notes

### S3
S3 is AWS object storage used to store files such as HTML, images, videos, backups, and documents in buckets.

### S3 Bucket
A bucket is a container in S3 where objects/files are stored.

### S3 Object
An object is a file stored inside an S3 bucket.

### S3 Versioning
S3 Versioning keeps multiple versions of an object so previous versions can be recovered.

### S3 Static Website Hosting
S3 can host static websites containing HTML, CSS, JavaScript, images, and other static files. Amplify can be used to deploy and host static website files stored in an S3 bucket.

### AWS Amplify
Amplify provides an easy way to build, deploy, and host web applications directly from a Git repository.

### Amplify Static Website
Amplify can automatically build and deploy a React, Angular, Vue, or static web application whenever code is pushed to Git.

### Amplify with S3
Amplify can be used to deploy and host a static website using website files stored in an S3 bucket.

### EC2
EC2 provides virtual servers in AWS for running applications and web servers.

### Frontend EC2
A frontend EC2 server hosts a client-side application such as a React production build using Apache or Nginx.

### Backend EC2
A backend EC2 server runs server-side applications such as FastAPI, Node.js, Java, or .NET APIs.

### Two EC2 Full-Stack Deployment
Two EC2 servers can separate the frontend and backend, allowing the browser to access the frontend server and the frontend to call APIs on the backend server.

### Security Group
A Security Group acts as a virtual firewall controlling inbound and outbound traffic to an EC2 instance.

### SSH
SSH provides a secure remote terminal connection to a Linux EC2 server.

### Apache/httpd
Apache is a web server that serves static files such as HTML, CSS, JavaScript, and images to users.

### Port 80
Port 80 is the standard network port used for HTTP web traffic.

### Port 443
Port 443 is the standard network port used for HTTPS secure web traffic.
